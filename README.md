# Microsoft Office Resources

Microsoft Office templates, reference materials, measurements,
documentation, examples, and tips for Word and other Office
applications.

`microsoft-office-resources` is a **collection repository**. The
collection has its own Semantic Versioning sequence, and independently
maintained components may also have their own Semantic Versioning
sequences.

The root `VERSION` identifies the collection version. A component
`VERSION` identifies that component's version. These are independent
sequences even when their values happen to match.

## Releases

Collection tags use `vX.Y.Z` and identify complete repository snapshots.
Released component-version milestones use namespaced tags such as
`usps-label-228/v1.0.0`. A collection release records the component
versions it contains.

GitHub Releases are **collection-level only**. Component tags are Git
milestones and do not receive separate GitHub Releases.

See `RELEASES.md` and `docs/versioning-and-releases.md`.
