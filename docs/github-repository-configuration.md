# GitHub Repository Configuration

Repository: `jefsko/microsoft-office-resources`

## Intended baseline

-   Visibility: Public
-   Default branch: `main`
-   Repository description: Microsoft Office templates, reference
    materials, measurements, documentation, examples, and tips for Word
    and other Office applications.
-   Collection release tags: annotated `vX.Y.Z`
-   GitHub Releases: collection-wide, created from matching collection
    tags

## Configuration verification

Before initial publication, record and verify the actual GitHub
settings, including visibility, default branch, About metadata/topics,
merge settings, branch protection/rulesets if used, and any enabled
repository features.

Do not claim a GitHub setting is enforced merely because a documentation
file describes the intended policy.
