# Changelog

## v1.0.0

Initial public repository version of the USPS Label 228 component. It
is formally marked by component tag `usps-label-228/v1.0.0` at the
collection v1.0.1 publication commit.

### Canonical template

-   Canonical filename: `USPS-Label-228-Template.dotx`.
-   Source lineage: Template Rev17 (originally Production Rev17).
-   Template Rev18 was created after Rev17, rejected/reverted, and
    permanently retired. Revision 18 will not be reused.

### Development history

-   Includes normalized Template Rev1 through Rev17.
-   Includes Calibration Rev1 and Rev2.
-   Historical `Production-Rev<N>` filenames were normalized to
    `Template-Rev<N>` for the public repository.
-   Office metadata accuracy was normalized under the documented v1.0.0
    repository-normalization process.

### Reference and assets

-   Includes the locked USPS Label 228 reference PNG.
-   Includes the locked USPS logo asset set as individual PNG files in
    source. Collection v1.0.1 publishes them as
    `USPS-Label-228-Logo-Assets.zip`.

### Documentation

-   Includes the project handover and repository-normalization audit.
