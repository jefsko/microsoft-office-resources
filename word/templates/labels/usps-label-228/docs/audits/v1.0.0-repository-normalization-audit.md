# USPS Label 228 v1.0.0 Repository Normalization Audit

**Status:** Normalization executed; repository copies only
**Date:** 2026-08-30

## Scope

This audit records normalization of 17 historical template revisions and two calibration documents for import into the public `microsoft-office-resources` repository. Original source files were not overwritten.

## Approved normalization

- Historical template filenames normalized from `USPS-Label-228-Production-Rev<N>.dotx` to `USPS-Label-228-Template-Rev<N>.dotx`.
- Calibration filenames retained.
- Title, Subject, Description, and Word core Revision property normalized for accuracy.
- Creator, empty LastModifiedBy, Created, Modified, TotalTime, Application/AppVersion, thumbnails, and other package content preserved.
- Descriptions intentionally avoid transient status terms such as accepted, current, latest, locked, or released.

## Integrity verification

For every normalized Office file, every OOXML package member except `docProps/core.xml` was verified byte-for-byte identical to its source counterpart. Thus the normalization changed only the approved core metadata plus, for template revisions, the external filename.

All 19 source files contain the same embedded `docProps/thumbnail.jpeg`; it was preserved unchanged. All inspected `LastModifiedBy` values are empty, Created and Modified are both `2013-12-23T23:15:00Z`, and TotalTime is 0; these values were intentionally preserved.

## Historical terminology and revision lineage

The source template files used the historical `Production` naming. Repository copies use the normalized artifact term `Template`. This naming change does not alter revision identity. Template Rev17 corresponds to the historical Production Rev17. Rev18 was subsequently rejected/reverted and is retired; the next template-development revision is Rev19.

## Verification result

**PASS:** No non-core OOXML package member changed in any of the 19 normalized Office files. All 19 normalized Office files were then rendered successfully to one-page PNGs and visually reviewed; no normalization-related layout defects were observed. The canonical `USPS-Label-228-Template.dotx` is a byte-for-byte copy of normalized Template Rev17.
